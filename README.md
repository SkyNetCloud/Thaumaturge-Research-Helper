# Thaumaturge Research Helper

A browser-based helper for connecting aspects in Thaumaturge 26.1.2 research notes. Aspect names, combinations, and icons are based on `Thaumaturge Mod`.

## Using 
Choose the **From** and **To** aspects from your research note and set **Min. Steps** to the number of empty spaces between them. Click **Find Connection** to search for the shortest valid path that connects the aspects while respecting that minimum length.

## Research and available aspects
The helper uses Thaumaturge's aspect combination definitions and includes the six primal aspects and all compound aspects from the bundled mod data. Use **Available Aspects** to disable aspects that you have not yet discovered through the in-game research and reading system. The helper avoids unavailable aspects where possible; when necessary, it finds a path using the fewest unavailable aspects.

The aspect selection is a planning aid and does not unlock or read research in-game.
