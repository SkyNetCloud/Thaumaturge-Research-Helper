    Help

    Use this helper with Thaumaturge research notes. Choose the note's starting and ending aspects in From and To, then set Min. Steps to the number of empty spaces between them. Click Find Connection to see a shortest valid sequence using Thaumaturge's aspect combinations.

    Use Available Aspects to mark the aspects you have discovered through Thaumaturge's research and reading system. Disabled aspects are avoided when possible; if no path exists without them, the helper uses the path with the fewest unavailable aspects. The aspect names, recipes, and icons are based on Thaumaturge 26.1.2 for NeoForge.
